# 全员维吉里乌斯映射

每位罪人各有四个独立人格：六章半血神备、九章常态、九章神备、九章半血神备。名称包含章节与模式，不覆盖原人格。全部90级；六章5500体力，九章3500体力；均无原版混乱线。成长系数为0，不受升级放大。

进场至少三槽，之后原游戏给予的新槽不删除。每回合按相应形态的原始出招序列填入最下方技能栏。半血触发记录后，下回合变身，不回复体力、不锁血。原技能ID直接引用私服原始数据，因此不覆盖技能、不修改点数、硬币或原生技能特效。

全部版本直接免疫流血伤害，流血本身及联动保留。六章必定正面；九章理智固定45并免疫理智伤害，隐藏被动固定95%正面。六章鲜血屏障不再给全队锁血。原剧情强制败北和阶段脚本不移植。

依赖同次安装的 BepInEx/plugins/VergiliusMappings/VergiliusMappings.dll。需要完全退出并重启私服后加载。构建与离线检查不等于实战验证；不会自动启动或关闭游戏。


空槽开战：正常选择至少1个技能后即可点原版开始按钮；例如7槽只选3槽，其余4槽不补选、不消耗技能。剧情要求强制使用特定技能/E.G.O时仍保留原检查。
