# 我的巴士私服自制 MOD 合集

我是 flower-frost。这个合集是我这段时间用 Codex 在 Limbus Company 私服里折腾出来的一套东西：能刷指定技能的插件、能自己安排阵容的“神秘斗蛐蛐”，还有独立 Boss 战和可以上手操作的映射人格。人格对战实验室后续也交给 Claude 做了完善。

最开始只是想自由打几场 Boss，不用反复跑剧情，也不想每次都被助战和出战限制牵着走。后来越做越多，连“把 Boss 搬到我方，按它原本的出招顺序打架”都安排上了，就干脆整理成一个合集。

**这里仅收录我这边制作的插件、关卡和人格。**

整理日期：2026-10-07。当前收录 **14 个自制插件 DLL、21 个自制 MOD 文件夹、27 个选关入口**。入口数包含实验室和同一 Boss 的不同版本，不是 27 个不同的 Boss。

## 先看这几句

- 这是目前安装版本的备份。人格对战实验室是 **0.5.1**。
- 关卡、人格、脚本、对应汉化和自制 MOD 目录里的配套素材一起收录，不再只有 DLL。
- 它不是游戏整包。游戏本体、第三方基础框架、账号、存档、个人配置、日志、崩溃转储和废弃预览缓存都不在里面。
- 这里“自制”指我做的移植、机制改造与整合，不表示原游戏的角色、模型、音效和汉化都由我原创。这些内容仍归原作者。
- 这次整理核对的是文件和版本，不是给每一种阵容重新做了一遍实战测试。我会说明功能和限制，不把“打包完成”写成“绝对没有 Bug”。

## 一、工具插件

### 指定技能刷卡：BattleDirector

这个插件最直接：选角色、选槽位、选技能，把指定技能刷到最下方的技能栏，再由自己选卡、拖线。

我想解决的是“想试一个隐藏或强化技能，却一直凑不齐它的出现条件”。每个槽位可以分开设置，不是把整个人物的牌都换成同一种。刷出来也不等于自动释放，更不代表技能自身的每一项条件都被删掉。

它还带着一些早期独立关的规则，比如瓦卢镜像战的血量与槽位、自由拼点、剧情提前退场处理，以及里恩共享安瓿的控制。别以为不用刷卡面板就能随便删 DLL，部分关卡也依赖它。

### 敌人等级与血量：EnemyLevelHealthTuner

不只是把血量乘几倍。我可以按关卡或敌人保存等级设置，让血量随等级成长，额外乘倍率，或者直接指定最大血量；混乱条按原百分比跟着缩放。

保存后重新进战斗生效，不是在当前回合里瞬间改血。要注意，普通血量调整不会顺便改写剧情门槛：比如中指的“400 血触发阶段”是专门的逻辑，不会因为血量翻倍就自动变成 800。

### 人格对战实验室：IdentityArena

也就是我说的“神秘斗蛐蛐”。它有自己的测试关，双方怎么打，先在局外面板里安排。

目前的功能包括：

- 选择原版人格作为敌方，设置等级、槽数和理智。
- 血量默认沿用人格自身成长，只有主动修改时才覆盖。
- 我方可以统一设置每人的槽数上限。“1 槽”是每人最多 1 槽，不是全队只能 1 槽。
- 理智既能按个人设置，也能统一设置。
- 按章节、关卡选择背景与 BGM，只取场景和音乐，不搬入那关的剧情、敌人和胜利条件。
- 局内查看敌方手牌、选择攻击或守备、调整指向，也可以按 F7 自动选目标。

指向某个人，不等于无视速度强行与他拼点。我希望它的操作尽量接近正常选牌，而不是点谁就绝对能拼谁。

0.5.1 的版本说明还包含：双方入场获得七种罪孽资源各 1，敌方出招积累资源，持有资源类被动的需求改为 1，共鸣条件保留原版，并过滤需要资源的场下支援被动。**这里禁用的是没上场人格给的支援，不是上场人格的战斗被动，也不是技能本身的援护。**

原版人格统一 70 级的处理也在这套功能里，自制人格不跟着统一改级。敌方选人范围目前仍是原版人格，不代表本合集里的每个自制 Boss 人格都能直接塞到实验室敌方。

以上按当前安装版及其说明整理，本次没有重新进入游戏逐项验收。

### 空槽开战与辅助功能

Partial Commands 放在维导映射的同一个 DLL 里，处理“有 7 槽，但这回合只想用 3 槽”的情况，也包含多槽界面适配。正常至少选一个技能后，剩余空槽不必硬填；剧情强制选特定技能的检查不一概取消。

另外还有指定人格等级恢复、立绘回退、我方场下支援禁用等功能，多数加载后自动运行。实验室规则与部分全局补丁有重叠，不能把一个开关理解为所有模式的总开关。

### 第三节：黑神的四个版本

| 入口 | 区别 |
| --- | --- |
| **黑神 · 全员解法** | 保留多阶段，Shift + Delete 的减威力解法对所有人开放。 |
| **黑神 · 无减威力** | 保留阶段，但 Shift + Delete 不给任何人这项减威力。 |
| **黑神 · 裁决变奏 [无混乱保护]** | 在无减威力版上改百分比伤害、护盾、钉子等机制；我方混乱时仍吃额外百分比伤害。 |
| **黑神 · 裁决变奏 [混乱保护]** | 与上一版相同，但我方已经混乱的角色免受这套额外百分比扣血，普通伤害仍在；逐目标判断。 |

裁决变奏是我改动最多的一版。按当前关卡文本，主要规则如下：

- 全阶段技能硬币威力 +1。
- 去 P 键惩罚、选金钉槽的追伤。满层金钉改为直接命中伤害的 10% 反伤。
- 搏动／停止只留标记作用，特殊技能根据标记降威力、接取拼点的关联仍在。
- 「死刑执行」「强制退场」「Shift + Delete」的额外百分比扣血，按**整个技能合计最多 15% 最大体力**处理，不是每币扣 15%；普通硬币伤害另算。
- 我方拼赢后，百分比追伤仍能生效，但拼赢者获得 15% 最大体力的临时护盾，由护盾正常承受伤害。
- 看守的「审判…！宣告…！定罪…！」和牧师的「西西弗系统」，引爆对应钉子时每层追加 1% 最大体力伤害；拼赢按钉数给护盾，并取消这招第五币新施加的拘束钉／Exception。
- 上面五招给的护盾在**下回合开始时消失**。其他来源的 Exception 一次扣 15% 当前体力，不按九层重复结算。
- 最后一条血首次到 33% 时，暂时保护血量并结束回合，保证收尾阶段能够出场；下回合出牌时解除这次保护，之后每轮至少两层守护。

15% 不是所有伤害的总上限。普通伤害还在，钉子引爆又按层数算，不要把它理解成“随便怎么打最多只掉 15% 血”。

### 第三节：赤红之神的三个版本

| 入口 | 转阶段与胜利条件 |
| --- | --- |
| **吱咿的记忆** | 保留原版记忆与通关机制，也保留原版阶段扣血下限，不是简单清空两条血。 |
| **血战到底** | 一阶段去剧情扣血下限，打到 0 血或满足原技能的 3 层记忆条件均可转阶段；回复最大体力的 80%，封顶最大体力。二阶段禁用记忆、保留“与吱咿一同的经历”，按普通循环打到 0 血结束。 |
| **无忆死战** | 双方删除记忆及“与吱咿一同的经历”等关联机制。一阶段打到 0 血转阶段，二阶段回满，再打到 0 血结束。 |

血战到底的“回复 80%”是加血，不是把当前血量强行设置成 80%。如果靠记忆提前转阶段，回复后可能就是满血。

## 四、里恩：未竟之谕

本质是一场更有压力的里恩战，不靠增加硬币数量硬堆难度，而是保留招式，再加可以互动的机制。结果发现还是太超模了，大概是7000血的维导水平（www)行动逻辑参考镜牢里恩，普通回合 7 槽；大招放过后重新充能，不再连着白送。

### 未削弱版

85 级、10500 体力、两阶段。当前累计加强是技能基础威力 +5、硬币威力 +3，**不赠送共享安瓿**。

新增机制主要有：

- **违谕刻痕**：不是指令对象却去接拼点，会积累压力；让指令对象亲自拼赢，可以压低刻痕。它影响拼点、速度、增伤和二阶段临时护盾，不是只能看着涨的数。
- **独行质询**：单通时启动，要求两回合内用两种不同的攻击技能分别拼赢。完成给机会，没完成给里恩下一回合强化，不能靠同一技能无限重复糊过去。
- **不可预知的变化无常**：指令加护提高攻等与攻击减伤，业压低超出保底的部分。加护到 0 仍保留 +6 攻等、20% 减伤；一阶段上限 +9／30%，二阶段上限 +12／40%。

### 削弱版 1

保留 10500 体力、7 槽和基本机制，降低技能点数，全队**共享一瓶安瓿**。

以 83 级映射雷横作为调试参照，后续普通技能基础威力再减 3、大招再减 5，拼碎后的不可摧毁硬币直接伤害也作了削弱。这里的减值相对削弱版调整前的数据，不能直接拿现在不断加强的未削弱版减一下，就当成削弱版数值。

“一阶段五五开、二阶段里恩略占优”是我的平衡目标，不是已经测出来的胜率。

### 鸿路映射人格

单独给鸿路，85 级、10500 体力。普通回合按 Boss 的 7 列行动表发牌，充能大招轮使用对应安排；上下候选牌同样服从该轮出招，不靠换牌绕开循环。

保留阶段、赫尔墨斯计数和相关机制。它不是最新未削弱 Boss 的实时数值镜像，后面对敌方做的加强没有全部同步过来。

`Rien - Shared Ampoules` 是共享安瓿配套，留给需要的版本。文件夹存在，不等于未削弱版又重新发两瓶。原文件夹里的“两瓶”早期说明不是当前规则。

## 五、映射人格

我做这些人格，不只是想复制一个大招。角色的味道还在于固定出招、转阶段和队友联动，所以它们有些并不采用普通人格那种随机发牌方式。

### 中指父女

`MiddleFather944 - Player Test` 给 12 名罪人各放了两个马蒂亚斯版本和绮罗，共 36 个。当前等级由配套插件校正为马蒂亚斯 **85**、绮罗 **65**，选人界面调用原生立绘。

以 9-44 的阶段、父女联动与出招为基础，包括拆包装、解放、过人的毅力和守备回合，不是把所有技能混成普通牌池。

插件还带着一项针对第三方 LCD 接待的适配：只有出战阵容符合“仅中指父女”时才切换对应逻辑，两个马蒂亚斯版本都参与识别。**LCD 接待原包不在本合集里**，这不影响这里的中指父女人格本身属于收录内容。

### 瓦伦希娜与卢西奥

每名罪人各一位母亲、一位儿子，共 24 个。当前等级：瓦伦 **85**、卢西奥 **70**。

参照的是我提取改造的 9-42 双人战，并核对主线行为，不是下载版瓦卢人格。

- 母子同队，开局启用母亲到场后的联动。
- 瓦伦单独出场，直接按小卢已阵亡后的状态与出招来。
- 小卢单独出场使用单人逻辑；另外安排了解鹿轮：猎人、猎人、猎人、解鹿、反击。
- 保留预知眼、预知、母子追击等机制，移除相关剧情负面限制。
- 解鹿取消“此前小技能败拼导致降威力”的限制，但保留红币被拼碎后的正常点数变化，不是碎币也能维持完整威力。

### LCD 三人组：9-44 行动复刻

摩西、以斯拉、维斯帕各覆盖 12 名罪人，共 36 个。

| 角色 | 等级 | 体力 |
| --- | ---: | ---: |
| 摩西 | 87 | 1806 |
| 以斯拉 | 75 | 1716 |
| 维斯帕 | 87 | 3111 |

按 9-44 实际入场数值和当回合行动表处理。每列上下候选及预备牌遵循同一安排，该守备的列就刷守备。保留次元包、支援防御、神备与三人联动，不带安瓿，不保留“某人阵亡全队判负”的剧情规则。

对战使用对应原版逻辑的敌方马蒂亚斯时，跟随他的真实阶段；打其他敌人时用 **F9** 预约下一阶段，下回合生效。只能往前推进，重新进关重置，不会因手动切阶段就回满血。

摩西红点蓄满后不直接演出判胜，而是继续赤红烟气循环，让人格在其他关里也能继续打。

### 旧版中指二战维斯帕

12 名罪人各一份，87 级、3111 体力、开场两槽。它与新版 LCD 的区别是：走可选攻击技能的普通抽取，不强制整套 9-44 每回合固定行动表。反击和支援防御保留，去剧情判负。

想自由玩维斯帕就选旧版，想复刻三人组的战斗节奏就选新版。下载的默尔索黄鱼叉普通／削弱版不是这套，这次没有打包。

### 维吉里乌斯

每名罪人四版，共 48 个，全部 **90 级**：

### 黑神

12 名罪人各一份，90 级。把多阶段、多形态一起搬过来，不是只挑最终形态做一个普通人格。

生命进程结合各阶段血量，通过阶段保护推进；实体拘束之烛保留。移到我方后，金钉技能槽的惩罚对象对应转向敌方，不反过来惩罚自己选牌。

人格与“裁决变奏”敌方关分别管理，敌方新版硬币 +1 不代表人格也自动吃到了同样的改动。

## 八、安装与撤回

目录按私服结构摆放：

```text
lcb-custom-plugins/
  README.md
  manifest.json
  BepInEx/
    plugins/
      BattleDirector/
      IdentityArena/
      ……共 14 个自制插件目录
      Lethe/
        mods/
          9-42 Lucio Valencia/
          Chapter 10 Part 3 Standalone/
          ……共 21 个自制 MOD 文件夹
```

只想备份，保存整个文件夹或压缩包就够了，不需要往游戏里复制。

要恢复时：

1. 完全退出私服，先备份原来的同名插件与 MOD。
2. 确认目标是兼容的私服环境，**不要放进官服**。
3. 按同样的目录结构复制需要的插件和 MOD，不要删空整个 plugins 再粘贴。
4. 重启后去 MOD 选关或人格列表找新增内容。
5. 想停用就把对应目录移出扫描范围。只改文件夹名不一定停用，备份 DLL 留在 plugins 里也可能被重复加载。

削弱里恩与鸿路里恩会用到未削弱版目录中的共用数据，别只拿走一个目录。其他专用人格也请同时保留表里对应的运行插件。

本包不带 BepInEx、Lethe、ModularSkillScripts、Motions、MTCustomScripts、SubUnitSpawner、CustomBundleLoader、ReStaged 等第三方基础组件，也没有游戏资源缓存；仍需要原来兼容的环境。有些立绘、语音和模型是运行时调用游戏资源，不会全部放在 MOD 目录里。

**部分插件绑定了我这套私服的路径和游戏本体版本。** 换电脑、改路径或更新游戏后，不保证复制就能用。这首先是一份当前环境备份，不是面向所有电脑的一键安装器，不要靠删除版本检查硬装。

## 九、旧说明、汉化与反馈

自制 MOD 文件夹里原有说明、脚本和素材按现状保留。有些说明是早期记录，还写着瓦伦 77 级、未削弱里恩两瓶安瓿或初版维导血量，不一定代表现在的数据，别把不同时期的规则拼到一起。文件清单和校验值见 `manifest.json`。

本包包含这些 MOD 自带的中文，不是零协会汉化的完整安装器。原游戏、汉化和第三方框架的权利仍归各自作者；我不会因为做了移植，就给原素材另起一个原创署名。

如果遇到问题，告诉我用了哪关、什么队伍、第几回合、做了什么操作，比一句“又不行了”更容易定位。日志可以单独留存，公开发之前记得去掉账号与登录信息。

这个合集是我边玩边折腾出来的：想试招就开工具，想认真打就选独立关，想让原本只能看着的 Boss 亲自上场就玩映射人格。至于一屋子 Boss 能打成什么样，那就自己试试吧。
